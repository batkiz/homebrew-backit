# backit for Homebrew

与 [backit](https://github.com/batkiz/backit) 一起维护的 homebrew tap。

会把 backit 中也有、官方又没有提供 homebrew 安装方式的软件收录进来。

## 安装

```sh
brew tap batkiz/backit
brew trust --tap batkiz/backit
```

## English

This Homebrew tap is maintained alongside [backit](https://github.com/batkiz/backit).

It includes software from backit that has no official Homebrew installation method.

### Installation

```sh
brew tap batkiz/backit
brew trust --tap batkiz/backit
```
